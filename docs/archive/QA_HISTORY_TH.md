# บันทึก QA จากคู่มือรุ่นก่อน

ย้ายเก็บ 1 พฤศจิกายน 2026 เพื่อแยกหลักฐานในอดีตออกจากวิธีใช้ปัจจุบัน ตัวเลข/เวอร์ชันด้านล่างเป็นผลครั้งที่เขียน ไม่ใช่ผลทดสอบใหม่ของการจัดเอกสาร ดูงานรอตรวจจริงใน [แผนหลัก](../ROADMAP_TH.md)

- ไม่ได้ทดสอบแพ็ก installer หรือ benchmark CPU/RAM ในงานนี้

## จาก SPEECH_TH.md

### บันทึกเดิม

`npm test` ครอบคลุมการตั้งค่า การยินยอม คีย์ที่ขาด การยกเลิก ข้อผิดพลาดบริการ และการเตรียมข้อความ โดยใช้บริการจำลองสำหรับ OpenAI จึงไม่มีค่า API จากการทดสอบ

`node scripts/smoke-speech.js` ใช้กับแอป `--dev` บน Windows เพื่อทดสอบเสียง Windows จริง การเล่น/หยุด และหน้าตั้งค่าออนไลน์ เครื่องทดสอบต้องมีเสียงอังกฤษติดตั้งอย่างน้อยหนึ่งตัว

ยังไม่ได้ทดสอบคุณภาพเสียงไทยจาก OpenAI แบบเรียกบริการจริง เนื่องจากไม่มีคีย์สำหรับการทดสอบ และยังไม่ได้ประเมินเสียงไทย Windows บนเครื่องที่ติดตั้งเสียงไทยแล้ว

อัปเดต QA 0.7.0: ทดสอบสร้างเสียงไทย Edge ชายและหญิงจริง พร้อม decode/playback ใน Electron; ทดสอบเปิด Notepad จริง → ถามยืนยันด้วยเสียงไทย → “ไม่ใช่” ไม่ปิด → “ใช่” จึงปิด โดยจำลองเฉพาะ STT transcript เพื่อทดสอบเส้นทางคำสั่งซ้ำได้ ไม่มีการเรียก LLM/OpenAI ใน smoke นี้

แหล่งอ้างอิง: [node-edge-tts](https://github.com/SchneeHertz/node-edge-tts), [การเปลี่ยนโปรโตคอลของ Edge TTS](https://github.com/rany2/edge-tts/issues/490)

- Smoke test เปิดไมค์จริง 48 kHz และปล่อยอุปกรณ์จริง; ลำดับ review/auto/follow-up ใช้ STT และ Chat จำลองเพื่อไม่สั่งงาน PC จริง
- ถอดคลิปเสียงไทยสาธารณะจริงด้วย small-q5_1 ได้ข้อความไทยในประมาณ 2.5 วินาทีบนเครื่องทดสอบ แต่ยังมีคำผิด ไม่ถือว่าผ่านการวัด WER หรือตรวจคำเรียกเสียงจริงครบชุด
- ไม่มีการเรียก OpenAI แบบเสียเงินจริงใน QA ครั้งนี้ ยังต้องทดสอบคุณภาพออนไลน์ด้วยบัญชีผู้ใช้

รันทดสอบ: `npm test` และเมื่อเปิดแอปด้วย `--dev`: `node scripts/smoke-listening.js`
