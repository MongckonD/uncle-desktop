# เสียงพูดใน Uncle Desktop

ตรวจเทียบ source 0.23.10 วันที่ 1 พฤศจิกายน 2026; ไม่ใช่การทดสอบคุณภาพเสียงจริงใหม่

เปิด ตั้งค่า › เสียงและไมค์ › **เสียงพูดภาษาไทย…** เลือกบริการ/เสียงแล้วกดทดสอบ ก่อนเปิดอ่านคำตอบอัตโนมัติ ระบบถอดเสียงไมค์แยกจาก TTS ดู [สั่งงานด้วยเสียง](VOICE_COMMANDS_TH.md)

## เลือกบริการ

| บริการ | การประมวลผล | สิ่งที่ต้องเตรียม / ข้อจำกัด |
|---|---|---|
| เสียงของเครื่อง | Windows voices หรือ macOS `say` | ต้องติดตั้งเสียงที่รองรับภาษาไทย; รายการเสียงขึ้นกับระบบ |
| Edge Thai | ออนไลน์ | เสียงเปรมวดี/นิวัฒน์ ไม่ต้องใส่ API key แต่ต้องยินยอมส่งข้อความและใช้อินเทอร์เน็ต |
| Kokoro | ในเครื่องหลังดาวน์โหลด | ดาวน์โหลดโมเดลประมาณ 90 MB ครั้งแรก; ภาษาไทยผ่านกฎแปลงเสียง อ่านได้แต่มีข้อจำกัดสำเนียง |
| OpenAI | ออนไลน์ | API key ของบริการและ consent; backend ใน source ใช้ `gpt-4o-mini-tts`/WAV |
| ElevenLabs TTS | ออนไลน์ | API key และเสียง/Voice ID; เป็นบริการอ่านข้อความ ไม่ใช่ Voice Agent สนทนาต่อเนื่อง |
| Fish Audio | ออนไลน์ | API key และ optional reference voice; คุณภาพภาษาขึ้นกับโมเดล/เสียง |
| เซิร์ฟเวอร์ของคุณ | ตาม URL | OpenAI-compatible `/v1/audio/speech`, โมเดลและเสียงของเซิร์ฟเวอร์; ถ้าไม่ใช่ loopback ต้องยินยอมส่งข้อความ |

เสียงเครื่องและ Kokoro ไม่ส่งข้อความไป cloud เพื่อสังเคราะห์เสียง ส่วนบริการออนไลน์ใช้โควตา/ค่าบริการตามบัญชีและอาจไม่พร้อมใช้งานได้ รายการข้างต้นแสดง backend ที่มีใน source ไม่รับรองสิทธิ์หรือราคา ณ ปัจจุบันของบริการ

## การใช้และหยุดเสียง

- **ทดสอบเสียง** อ่านข้อความตัวอย่างที่แก้ได้; **อ่านข้อความตอบล่าสุด** อ่านคำตอบแชต
- **อ่านคำตอบแชตอัตโนมัติ** ปิดเป็นค่าเริ่มต้น เปิดเองได้ คำตอบจากคำสั่งเสียงใช้เสียงที่ตั้งไว้แม้ไม่ได้เปิดอ่านแชตพิมพ์อัตโนมัติ
- เมื่ออ่านแชตอัตโนมัติ ระบบทยอยอ่านประโยคที่ครบจากข้อความระหว่าง AI ตอบ จึงเริ่มได้ก่อนคำตอบเต็มจบ; จังหวะขึ้นกับข้อความและเวลาเตรียมเสียงของ provider
- **หยุดเสียง** ยกเลิกทั้งคำขอสร้างเสียงและเสียงที่เล่น ผลที่มาช้าจะไม่ถูกเล่นต่อ การ mute แอปหรือเปลี่ยนตัวละครหยุดเสียงด้วย
- ปรับ volume, rate และเอฟเฟกต์ pitch/robot/glitch/layers ได้ตามหน้าตั้งค่า
- แต่ละคำขอ TTS รับข้อความไม่เกิน 2,000 ตัวอักษร ตัวเตรียมข้อความข้าม code blocks และ URL; ไม่อ่านภาพหน้าจอหรือส่งเสียงไมค์ไปพร้อมคำขอ TTS

## Kokoro ภาษาไทยแบบทดลอง

`src/main/thai-g2p.js` แปลงข้อความไทยเป็น phonemes ตามกฎภาษาไทยในเครื่อง รองรับตัวเลข เวลา เลขไทย คำซ้ำ ตัวย่อ อักษรนำ/คำควบกล้ำ สระ ตัวสะกดและคำอ่านยกเว้น

เสียงจีน **Xiaoxiao/Xiaobei** ได้ข้อมูลวรรณยุกต์จากกฎด้วย ส่วนเสียงอื่นอาจมีสำเนียง/คำอ่านต่างกัน Kokoro ไม่ได้เป็นโมเดลที่ฝึกเสียงไทยโดยตรง หากแก้คำอ่านเฉพาะให้ตรวจรายการ `RESPELL` ใน source ระบบโหลด Kokoro ล่วงหน้าเมื่อเลือกใช้งานเพื่อลดเวลารอครั้งแรก แต่ความเร็วจริงขึ้นกับเครื่อง

## ตัวละครขยับตามเสียง

renderer วัดระดับเสียงแล้วใช้ท่า/เฟรมและ motion ที่ตัวละครมี ไม่ใช่ phoneme lip sync การมีเสียงพูดไม่ได้แปลว่าทุกตัวมีภาพปากหลายระดับ ดู [ตัวละคร](CHARACTERS.md) และ [pipeline](character-sprites.md)

## ความเป็นส่วนตัวและ Voice Agent

คีย์จัดการผ่าน main process และที่เก็บคีย์ของแอป ไม่ส่งค่าคีย์กลับไปแสดงใน renderer เลือกบริการให้ตรงกับความยินยอม การอ่านข้อความออนไลน์ส่งข้อความให้บริการนั้น; การตั้ง server ของตนเองต้องพิจารณาปลายทางด้วย

หากต้องการสนทนาแบบพูดแทรก ให้ตั้ง [ElevenLabs Voice Agent](VOICE_AGENT_TH.md) ซึ่งมี consent และวงจรเชื่อมต่อแยกจาก ElevenLabs TTS
