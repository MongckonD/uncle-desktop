# คุยกับตัวละครผ่าน Telegram

ตรวจเทียบ source 0.23.10 วันที่ 1 พฤศจิกายน 2026; ผลทดสอบกับบริการ/เครื่องจริงแยกจากการตรวจเอกสารครั้งนี้
สั่งงาน ถามข้อมูล และรับแจ้งเตือนจากมือถือ ส่งเป็นข้อความ ข้อความเสียง รูป หรือวิดีโอสั้นได้ ตัวละครตอบกลับเป็นข้อความหรือเสียง

## ตั้งค่า (ประมาณ 2 นาที)

1. **สร้าง bot**
   - ใน Telegram เปิดแชตกับ [@BotFather](https://t.me/BotFather) แล้วพิมพ์ `/newbot`
   - ตั้งชื่อ bot และชื่อผู้ใช้ที่ลงท้ายด้วย `bot` เช่น `my_uncle_bot`
   - BotFather จะส่ง **token** มาให้ หน้าตาแบบ `123456789:AA…`
2. **ใส่ token ในแอป**
   - บนคอม: คลิกขวาที่ตัวละคร › **ตั้งค่า…** › แท็บ **Telegram** › **ใส่ bot token…**
   - วาง token แล้วกด Enter ตัวละครจะบอกชื่อ bot ที่เชื่อมแล้ว
3. **ผูกกับแชตของคุณ**
   - กด **ผูกกับแชตของคุณ…** Telegram จะเปิดแชตกับ bot ของคุณ
   - กด **Start** ภายใน 10 นาที (หรือพิมพ์ `/start` ตามด้วยรหัส 6 หลักที่ตัวละครบอก)
   - bot จะตอบ "เชื่อมกับ Uncle Desktop แล้ว"

หลังผูก bot จะตรวจ Telegram User ID ตามรายชื่อที่อนุญาต รวมผู้กดปุ่มในกลุ่ม ผู้ที่ไม่อยู่ในรายชื่อส่งคำสั่งไม่ได้ ใช้ `/whoami` ดู User ID เพื่อเพิ่มในหน้าตั้งค่าบนคอม

## ใช้งาน

คำสั่งเสียง “เพิ่มเสียง”, “ลดเสียง”, “ตั้งเสียง 40 เปอร์เซ็นต์”, “เปิดเสียง Windows” ใช้การปรับเสียงระบบโดยตรงผ่านงานควบคุมที่ตรวจสิทธิ์เดิม ไม่ต้องให้โมเดลเดาปุ่ม Windows เพิ่ม/ลดครั้งละ 10 จุดเมื่อไม่ระบุจำนวน การเปิดเสียงจาก 0 เริ่มที่ 25% และการเพิ่มเสียงปลด mute ด้วย “เปิดเสียง” ที่ไม่ระบุเป้าหมายจะทำ Windows ก่อนแล้วให้ AI ตรวจแท็บ/ตัวเล่นในเบราว์เซอร์; “เปิดเสียงเบราว์เซอร์” ทำเฉพาะเบราว์เซอร์ ต้องมีโมเดลควบคุมที่พร้อมใช้งาน และต้องยืนยันผลจากสถานะปุ่มจริง

ข้อความเสียงที่เป็นคำสั่งควบคุมคอม เช่น “กดเล่นเพลงให้หน่อย” จะถูกแยกจากการคุยปกติ เมื่อเปิดขอ PIN บอตแสดงงานที่ถอดได้แล้วให้พิมพ์ PIN ยืนยันภายใน 90 วินาที จึงเริ่มงานด้วยสิทธิ์ควบคุมเดิม; เมื่อปิดขอ PIN ผู้ใช้ที่อยู่ใน allowlist เริ่มคำสั่งได้ทันที ต้องเปิด “สั่งงานคอมจากมือถือ” ก่อน PIN ใช้ยืนยันงานเดียว ไม่ปลดล็อกทั้งแชต; ผิดสามครั้ง หมดเวลา หรือส่ง `/cancel` จะยกเลิกงาน ตัวเลข PIN ไม่ส่งให้โมเดลแชต โหมด `/code` ยังคงส่งเสียงให้ Coding Agent ตามเดิม

| ส่ง | ตัวละครทำอะไร |
|---|---|
| 💬 ข้อความ | ตอบ และใช้เครื่องมือได้ เช่น ดูนัด สรุปเมล หรือเครื่องมือ MCP อื่น |
| 🎙 ข้อความเสียง | ถอดเสียงไทย (ตามที่ตั้งไว้ในหน้าไมค์) บอกว่าได้ยินว่าอะไร แล้วตอบ |
| 🖼 รูป | ดูรูปแล้วตอบตามคำบรรยายรูป เช่น "อ่านใบเสร็จนี้", "แปลป้ายนี้" |
| 📄 ไฟล์ข้อความ | อ่าน txt, md, csv, json, log และไฟล์โค้ด (ไม่เกิน 2 MB) แล้วตอบหรือสรุปตามคำบรรยาย ยังไม่รองรับ PDF และไฟล์ไบนารี |
| 🎬 วิดีโอสั้น | ดึงภาพ 6 เฟรมและถอดเสียงในคลิป แล้วสรุป (ไม่เกิน 20 MB) |

**คำสั่ง** (พิมพ์ `/` จะมีเมนูคำสั่งขึ้นให้เลือก)
- `/new` เริ่มเรื่องใหม่
- `/help` ดูวิธีใช้
- `/status` ดูสถานะคอม: ว่างมานานเท่าไหร่ เพลงที่เล่นอยู่ งานควบคุมเครื่อง Agent สดที่เปิดอยู่
- `/say ข้อความ` ให้ตัวละครพูดข้อความออกลำโพงคอม (ต้องเปิดสวิตช์สั่งงานคอม ไม่ต้องใส่ PIN)
- `/music play|pause|next|prev|volup|voldown|mute` ควบคุมเพลงบนคอม (สวิตช์เดียวกัน)

**งานที่ส่ง เขียน หรือลบข้อมูล:** เช่น ส่งเมลหรือสร้างนัด bot จะถามพร้อมปุ่ม **✓ อนุญาต / ✗ ไม่ต้อง** ถ้าไม่กดภายใน 5 นาทีถือว่าไม่ทำ

## 💻 Vibecode: สั่ง Claude Code / Codex จากมือถือ

โปรเจกต์อยู่ในโฟลเดอร์ Vibecode (ค่าเริ่มต้น `~/vibe-projects` เปลี่ยนได้ในแท็บ Telegram)

| คำสั่ง | ทำอะไร |
|---|---|
| `/create ชื่อ` หรือ `/create ชื่อ codex` | สร้างโปรเจกต์ใหม่ (git init) ใช้ Claude Code หรือ Codex แล้วเข้าโหมดเขียนโค้ด |
| `/projects` · `/project ชื่อ` | ดูรายชื่อ หรือเลือกโปรเจกต์ |
| `/code` · `/chat` | เปิด session สดของโปรเจกต์ที่เลือก (ทุกข้อความ เสียง และรูป ส่งให้ Agent) / กลับมาคุยปกติ |
| `/diff` | สรุปไฟล์ที่แก้ + ไฟล์ diff แนบมา |
| `/commit ข้อความ` | commit ทุกอย่าง |
| `/pr PIN` | สร้าง branch, push และเปิด pull request (ต้องมี remote และ `gh` login แล้ว) |
| `/undo PIN` | ย้อน commit ล่าสุด (`git revert`) |
| `/shot http://localhost:3000` | ภาพหน้าเว็บที่รันอยู่ในคอม |
| `/interrupt` | หยุดงานรอบนี้ของ Agent |

- ระหว่างทำงาน ตัวละครส่งความคืบหน้าเป็นระยะ เช่น "🔧 Edit: src/app.js"
- เสร็จแล้วส่งคำตอบสุดท้ายพร้อมปุ่ม **ดูสิ่งที่แก้** / **commit**
- ส่งรูป mockup ในโหมดเขียนโค้ด Agent จะดูรูปแล้วทำตาม
- **ขออนุญาตจากมือถือ:** ทุกครั้งที่ Claude Code ขอสิทธิ์รันคำสั่งหรือแก้ไฟล์ ปุ่ม ✓ / ✗ จะเด้งมาใน Telegram (ไม่ตอบใน 10 นาทีถือว่าไม่อนุญาต)
- Codex ทำงานใน sandbox ที่เขียนได้เฉพาะในโฟลเดอร์โปรเจกต์
- **แจ้งเตือนจาก Claude Code บนคอม:** รออนุมัติหรือทำงานเสร็จ ส่งเข้ามือถือด้วย

## 🧠 Agent สด (แบบ Remote Control ใช้ได้ทั้ง Claude Code และ Codex)

session ที่ทำงานค้างไว้บนคอม สั่งและดูได้ทั้งจากมือถือและจากหน้าต่าง **Coding Agent สด** บนคอม (คลิกขวาที่ตัวละคร › Coding Agent สด…) ตอบฝั่งไหนก่อนก็ได้

| คำสั่ง | ทำอะไร |
|---|---|
| `/new claude ชื่อโปรเจกต์ [งาน]` (หรือ `codex`) | เริ่ม session ใหม่ในโปรเจกต์ Vibecode |
| `/resume claude ชื่อโปรเจกต์` | ต่อจาก session ครั้งก่อนของโปรเจกต์นั้น |
| `/agents` · `/use รหัส` | ดู session ที่เปิดอยู่ / เลือก session |
| ข้อความหรือเสียง | ส่งเข้า session ที่เลือก ถ้า Agent กำลังทำงานอยู่ ข้อความจะถูกแทรกเข้างานรอบนั้น |
| `/interrupt` · `/end` | หยุดงานรอบนี้ / ปิด session |
| `/chat` | กลับมาคุยกับตัวละครตามปกติ |

- ความคืบหน้าขึ้นในข้อความเดียวที่ถูกแก้ทับไปเรื่อยๆ จบรอบแล้วส่งคำตอบเต็มมาอีกข้อความ
- **ขออนุญาต:** ปุ่ม ✓ อนุญาต / ✓ ตลอด session / ✗ ไม่อนุญาต (ต้องเปิด "อนุมัติงานจากมือถือ")
- **Agent ถามกลับ:** กดตัวเลือก หรือพิมพ์ตอบได้เลย
- คำถามค้างหมดอายุเมื่อจบรอบ สั่ง interrupt หรือปิด session; ปุ่มเก่าใช้อนุมัติไม่ได้ และตรวจสวิตช์อนุมัติจากมือถือซ้ำตอนตอบ หาก Agent หลุดให้เปิด/ต่อ session ใหม่
- `/code` และ `/create` ของ Vibecode เปิด session สดให้อัตโนมัติ และ `/diff` `/commit` `/pr` `/undo` ใช้กับโปรเจกต์ของ session ที่เลือก
- Codex ทำงานใน sandbox ที่เขียนได้เฉพาะโฟลเดอร์โปรเจกต์ และถามก่อนรันคำสั่งที่ไม่ปลอดภัย
- เลือกโมเดลต่อ Agent ได้ใน `config.json` › `vibe.models` เช่น `{ "codex": "gpt-5.6-luna" }`

## 🖥 สั่งคอมจากมือถือ (ปิดไว้เป็นค่าเริ่มต้น)

เปิดสวิตช์ที่เกี่ยวข้องในแท็บ Telegram และอนุญาตควบคุมเครื่องบนคอม ค่าเริ่มต้นเปิด **ขอ PIN**; ตารางนี้แสดงรูปแบบเมื่อเปิด PIN หากปิดในหน้าตั้งค่า คำสั่งเริ่มงาน/ดูหน้าจอ/พลังงานไม่ต้องใส่ PIN แต่ยังตรวจ User ID และสิทธิ์เดิม:

| คำสั่ง | ทำอะไร |
|---|---|
| `/screen PIN` | ส่งภาพหน้าจอคอมมาให้ (ตัวละครบอกบนคอมทุกครั้ง) |
| `/pc PIN งาน` | สั่งงานควบคุมเครื่อง เช่น `/pc 1234 เปิด Spotify เล่นเพลงชิล` ใช้ระดับความปลอดภัยเดียวกับบนคอม เสร็จแล้วแจ้งกลับ |
| `/lock PIN` · `/sleep PIN` · `/shutdown PIN` · `/restart PIN` | ล็อก พัก ปิด หรือรีสตาร์ทเครื่อง |
| `/pc PIN` แล้วส่งข้อความเสียง | สั่งงานด้วยเสียง (ส่งเสียงภายใน 2 นาที) |
| `/tell ข้อความ` | บอกเพิ่มระหว่างงานกำลังทำ เช่น "เบาเสียงด้วย" |
| `/pcstop` | หยุดงานบนคอมที่สั่งจากมือถือ |

**ระหว่างงานจากมือถือ** (ตั้งค่าได้ในแท็บ Telegram ใต้สวิตช์สั่งงานคอม):
- **ถามอนุมัติและคำถามของ AI ในมือถือ:** ปุ่ม ✓/✗ เด้งมาใน Telegram ถ้า AI ถามกลับ พิมพ์หรือส่งเสียงตอบได้ (5 นาที) ยังตอบบนคอมได้เหมือนเดิม
- **ส่งความคืบหน้าทีละขั้น:** เช่น "🔧 เปิด Spotify"
- **ส่งภาพหน้าจอเมื่องานจบ:** ต้องเปิดสวิตช์ส่งภาพหน้าจอด้วย

## ตั้งค่าในแท็บ Telegram

- **ขอ PIN ก่อนสั่งงานจาก Telegram:** เปิดไว้ตามค่าเริ่มต้น ปิดได้เพื่อให้ User ID ที่อนุญาตสั่งได้ทันที ทั้งข้อความ `/pc งาน` และข้อความเสียงที่เป็นคำสั่งควบคุม สิทธิ์และสวิตช์ควบคุมบนคอมยังมีผลเหมือนเดิม
- **ผู้ใช้ที่อนุญาตให้สั่งงาน…:** กรอก Telegram User ID ตัวเลข คั่นด้วยจุลภาค สูงสุด 50 คน ใช้ `/whoami` ในแชตบอตเพื่อดู ID บัญชีที่ผูกแชตส่วนตัวเดิมจะได้รับสิทธิ์อัตโนมัติ; เมื่อผูกใหม่จะจำ ID ผู้ที่ผูกไว้ กลุ่มตรวจ ID ผู้ส่งจริงรวมถึงผู้กดปุ่ม จึงไม่ให้สิทธิ์ทุกคนในกลุ่มตาม Chat ID การลบ ID จะหยุดรับคำสั่งใหม่จากคนนั้น การเลิกผูกล้างรายชื่อทั้งหมด

- **ส่งแจ้งเตือนเข้ามือถือ:**
  - ทุกครั้ง
  - เฉพาะตอนไม่อยู่หน้าคอม (ไม่แตะเมาส์หรือคีย์บอร์ด 5 นาที)
  - ไม่ส่ง

  แจ้งเตือนที่ส่ง: เมลสำคัญ, นัดใกล้ถึง, ข่าว และสถานะงาน
- **ตอบกลับเป็นเสียง:** เมื่อคุณส่งเสียงมา / ทุกครั้ง / ไม่ตอบเป็นเสียง ใช้บริการเสียงที่เลือกในหน้าเสียงพูด
- **พูดคำตอบออกลำโพงคอมด้วย:** (ปิดไว้เป็นค่าเริ่มต้น) คำตอบที่ส่งเข้า Telegram จะขึ้นในบับเบิลของตัวละครและพูดออกลำโพงคอมด้วย เหมือนสั่งจากคอมโดยตรง
- **คุยและถามข้อมูลจากมือถือ:** ปิดได้ถ้าต้องการแค่แจ้งเตือน
- **อนุมัติงานจากมือถือ:** ถ้าปิด งานที่ต้องอนุมัติจะไม่ทำเมื่อสั่งจากมือถือ

## ข้อควรรู้

- **คอมต้องเปิดและแอปต้องรันอยู่:** ตัวละครดึงข้อความจาก Telegram เอง ไม่มีเซิร์ฟเวอร์กลาง
- **ข้อมูลผ่าน Telegram:** ข้อความ รูป และเสียงผ่านเซิร์ฟเวอร์ของ Telegram แล้วส่งให้ AI ที่คุณเลือกบนคอม ถ้าใช้ Ollama และ Whisper ในเครื่อง ส่วน AI ก็อยู่ในเครื่องทั้งหมด
- **การเก็บข้อมูล:** รูป/คลิปแชตปกติประมวลผลในหน่วยความจำ; Local STT อาจใช้ WAV/transcript ชั่วคราวและล้างใน finally ข้อความใช้ประวัติสนทนาเดิม ส่วนรูปที่ส่งให้ Coding Agent จะบันทึกลงโปรเจกต์และส่ง path ให้ Agent อ่าน จึงต้องจัดการไฟล์นั้นในโปรเจกต์ด้วย
- **token:** เก็บแบบเข้ารหัสในเครื่อง ถ้า token หลุด ให้พิมพ์ `/revoke` กับ @BotFather แล้วใส่ token ใหม่
