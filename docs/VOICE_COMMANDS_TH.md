# สั่งงานด้วยเสียง — Uncle Desktop

ตรวจเทียบ source 0.23.10 วันที่ 1 พฤศจิกายน 2026; ผลทดสอบกับบริการ/เครื่องจริงแยกจากการตรวจเอกสารครั้งนี้
## บริการถอดเสียงและภาษาไทย

- เลือก Local AI, Gemini หรือ OpenAI แยกจากโมเดลแชตได้ บันทึกคีย์เข้ารหัสในหน้าสั่งงานด้วยเสียง
- Local มี Whisper small เดิม และ Thonburian Thai medium Q5_0 (~539 MB) ที่ฝึกภาษาไทย ดาวน์โหลดแยกจากตัวติดตั้ง พร้อมตรวจ SHA256 และ pin revision
- ตัวเลือกโมเดล Local ใช้กับคำเรียกด้วย ไม่อัปโหลดเสียงรอคำเรียก เมื่อเรียกพร้อมคำสั่งและเลือก cloud จะถอดคลิปนั้นซ้ำด้วยบริการที่เลือกหลังพบคำเรียก หากผลใหม่ไม่ชัดจะให้พูดคำสั่งอีกครั้ง
- Gemini ใช้ gemini-3.5-transcribe / Interactions API แบบ verbatim, th-TH + en-US, store:false; ไม่ใช้โมเดลตอบแชตมาเดาคำสั่ง
- เพิ่มศัพท์เฉพาะ คั่นด้วยจุลภาค (สูงสุด 600 ตัวอักษร) คำเรียกถูกเพิ่มในบริบทอัตโนมัติ ไม่แก้ transcript ด้วย fuzzy replacement
- ปรับเวลาหยุดเว้นจังหวะได้ 0.6–2.5 วินาที ค่าเริ่มต้น 1.3 วินาที
- ปุ่มทดสอบเสียงไม่ส่งคำสั่ง โหมดกดพูดทดสอบบริการที่เลือก โหมดรอคำเรียกทดสอบ Local แสดง transcript / โมเดล / เวลา
- Typhoon ยังไม่ได้รวม: upstream ระบุว่า Windows ไม่รองรับอย่างเป็นทางการ จึงเลือก Thonburian ที่ทดสอบบน runtime Windows เดิมแล้ว

ผลทดลอง Local/Gemini เดิมอยู่ใน [บันทึก QA](archive/QA_HISTORY_TH.md); ยังต้องทดสอบเสียงมนุษย์และไมค์จริงตาม [แผนงาน](ROADMAP_TH.md)

- https://huggingface.co/suebphatt/thonburian-whisper-ggml (community GGML conversion)
- https://github.com/scb-10x/typhoon-asr

## โหมดสนทนาอัตโนมัติและถามยืนยัน

- ค่าเริ่มต้นใหม่ส่งคำสั่งเองหลังถอดเสียง ไม่ต้องกดส่ง; ยังเปิด “ตรวจข้อความก่อนส่ง” กลับได้
- เปิดแอป เพลง ปรับเสียง และตั้งเตือนที่ระบุเวลาครบ ใช้ parser/เครื่องมือเดิมโดยตรง ไม่รอให้ LLM เดาว่าทำแล้ว
- ปิดโปรแกรมหรือเปิดรายการที่อาจรันสคริปต์: สรุปรายการแล้วถามยืนยันก่อน พร้อมปุ่มสำรอง ตอบ “ใช่ / ยืนยัน / ทำเลย” เพื่อทำ หรือ “ไม่ใช่ / ยกเลิก” เพื่อหยุด ไม่ต้องเรียกชื่อซ้ำ
- ชื่อโปรแกรม/เวลาที่ไม่ครบจะถามข้อมูลเพิ่ม เช่น “ต้องการให้เตือนเมื่อไหร่” ไม่เลือกแทน รองรับเลขเวลาที่ถอดเป็นคำไทยหนึ่งถึงเก้าสิบเก้า เช่น “อีกห้านาที”
- หลังเสียงถามจบ รอคำตอบ 20 วินาที ถ้าหมดเวลาหรือปิดไมค์ ยกเลิกทันที ผลเสียงที่มาช้าก็ใช้ยืนยันไม่ได้
- ถ้าต้องกดส่งเองแล้วมีคำถามยืนยัน โปรแกรมเปิดไมค์ต่อให้รับคำตอบ และแสดงแถบปิดไมค์
- ใช้เสียง TTS ที่เลือกไว้สำหรับคำถามและคำตอบจากเสียง แม้ปิดอ่านแชตพิมพ์อัตโนมัติ หากบริการเสียงไม่พร้อมจะแสดงคำถามบนจอและยังใช้เสียง/ปุ่มตอบได้
- ตัวแยกคำสั่งด่วนไม่รองรับลบไฟล์ ซื้อของ โอนเงิน หรือส่งข้อความอิสระ งานหลายขั้นตอนหรือเครื่องมือ MCP มีขอบเขต/สิทธิ์ของตัวเอง ดู [ควบคุมเครื่อง](COMPUTER_CONTROL_TH.md)
- การแยกคำสั่งใช้เครื่องมือที่มีอยู่และเงื่อนไขที่ระบุ ไม่ใช่โมเดลตรวจความมั่นใจของ STT จึงตรวจจับการฟังผิดทุกกรณีไม่ได้; คง review mode สำหรับผู้ที่ต้องการตรวจเอง

ทดสอบเพิ่มด้วย `node scripts/smoke-voice-actions.js` เมื่อเปิด `--dev`: ใช้ parser และเครื่องมือจริงเปิด Notepad ว่าง (เฉพาะเมื่อไม่มี Notepad ของผู้ใช้เปิดอยู่), ปฏิเสธการปิด แล้วพูดยืนยันเพื่อปิด ไม่เรียก API/LLM ในเทสต์นี้ และจำลองเฉพาะ transcript กับเสียง TTS

อัปเดตแก้บั๊ก 0.6.2: ช่อง **เสียงที่ถอดได้ล่าสุด** แสดงผลแม้ไม่ตรงคำเรียก พร้อมเหตุผลที่ไม่ส่งคำสั่งค้างไว้; การเทียบคำเรียกไทยยอมรับวรรณยุกต์ที่ STT ถอดต่างกัน แต่ยังต้องตรงพยัญชนะ/สระและอยู่ต้นประโยค ไม่มีการส่งคำสั่งที่ไม่ผ่านคำเรียกอัตโนมัติ

คลิกขวาที่ตัวละครหรือไอคอนถาดระบบ → **สั่งงานด้วยเสียง / ตั้งคำเรียก…**

## เริ่มใช้งาน

1. ตั้งค่า AI แชตให้คุยได้ก่อน คำสั่งเสียงจะใช้ AI และเครื่องมือแชตเดิม
2. เลือกไมค์ หากไม่เห็นชื่อให้กด **อนุญาตไมค์และรีเฟรชรายชื่อ**
3. เลือกบริการถอดคำสั่ง:
   - **ในเครื่อง**: เลือก Whisper small หรือ Thonburian Thai medium แล้วดาวน์โหลดโมเดลที่เลือก ไม่ต้องใช้ Python/Ollama/API key; Windows x64 ใช้ whisper.cpp ที่แอปดาวน์โหลด ส่วน macOS ใช้ whisper-cpp ผ่าน Homebrew
   - **Gemini / OpenAI**: บันทึกคีย์ของบริการและติ๊กยินยอมส่งเสียงคำสั่ง ค่าใช้จ่าย/โควตาขึ้นกับบัญชีของบริการ
4. เลือก **กดพูด**, **รอคำเรียก** หรือ **ฟังตลอด** แล้วกดเริ่มฟัง โหมดรอคำเรียกต้องมีโมเดลในเครื่องแม้เลือก Gemini/OpenAI สำหรับคำสั่ง
5. เลือกเสียงที่รองรับไทยในหน้าเสียงพูด โหมดสนทนาจะใช้เสียงนี้ตอบ/ถาม; แชตที่พิมพ์ยังใช้ตัวเลือกอ่านอัตโนมัติแยกกัน ดู [คู่มือ TTS](SPEECH_TH.md)

ไมค์ปิดทุกครั้งที่เริ่มโปรแกรมใหม่ ไม่มีการเปิดอัตโนมัติจากค่าที่บันทึกไว้

## กดพูด

กด **เริ่มฟัง** หรือ **Ctrl+Alt+V** แล้วพูด หยุดพูดตามเวลาที่ตั้ง (ค่าเริ่มต้น 1.3 วินาที ปรับได้ 0.6–2.5 วินาที) เพื่อจบประโยค หรือกดปุ่ม/คีย์ลัดอีกครั้งเพื่อจบเอง จากนั้นส่งอัตโนมัติ หรือรอกดส่งถ้าเปิด review ไว้ ไมค์จะถูกปล่อยหลังประโยค ยกเว้นมีคำถามยืนยัน/ถามรายละเอียดค้างอยู่

## คำเรียกปลุกที่ตั้งเอง

- กรอกหนึ่งคำเรียกต่อบรรทัด สูงสุด 5 คำ แต่ละคำเรียกยาว 2–60 ตัวอักษร เช่น `เฮ้ อังเคิล` และ `ลุงเดฟ`
- คำเรียกแยกจากชื่อตัวละคร ใช้กับตัวละครใดก็ได้
- ใช้ปุ่ม **ทดสอบคำเรียก** เพื่อดูว่าโมเดลได้ยินอะไร โหมดทดสอบไม่ส่งคำสั่งเข้าแชต
- คำเรียกต้องอยู่ต้นประโยค การเอ่ยชื่อกลางประโยคไม่ปลุก
- พูดคำเรียกพร้อมคำสั่งได้ เช่น “ลุงเดฟ เปิด Notepad” หรือเรียกก่อน แล้วพูดคำสั่งภายใน 10 วินาที
- หลังตอบ จะรอฟังต่ออีก 0–30 วินาทีตามที่ตั้งไว้ ค่าเริ่มต้น 10 วินาที เมื่อพ้นเวลา ต้องเรียกใหม่
- ถอดคำเรียกด้วย local STT ไม่ใช่โมเดล keyword เบา ๆ จึงใช้ CPU และอาจรอหลายวินาทีตามเครื่อง คำไทย/ชื่ออังกฤษที่เสียงใกล้กันอาจถอดต่างจากที่ตั้งไว้ ให้ใช้ผลทดสอบช่วยเลือกคำสำรอง

ตอนปลุกสำเร็จมีเสียงสั้นและตัวละครตอบสนอง ส่วนแถบไมค์บอกสถานะรอเรียก ฟัง ถอดเสียง หรือตอบ

## ฟังตลอด

เลือกโหมดฟังตลอดเพื่อรับประโยคโดยไม่ต้องมีคำเรียก ระบบกรองเสียง/ข้อความรบกวนบางชนิดแต่แยกผู้พูดไม่ได้ ถ้าเลือก cloud เสียงที่ส่งไปถอดแต่ละประโยคออกนอกเครื่องและอาจมีค่าใช้จ่าย ควรเปิดตรวจข้อความก่อนส่งเมื่อมีเสียงทีวีหรือคนอื่นคุยอยู่

## ตรวจข้อความหรือสนทนาอัตโนมัติ

**ตรวจข้อความก่อนส่ง** เป็นตัวเลือก (ตั้งแต่ 0.7.0 ปิดเป็นค่าเริ่มต้นใหม่) ถ้าเปิดไว้ ให้แก้ transcript แล้วกดส่ง หรือกดล้างข้อความเพื่อกลับไปรอเรียก

ปิดตัวเลือกนี้เพื่อส่งข้อความทันทีหลังถอดเสียง เหมาะกับคุยต่อเนื่อง แต่การรับเสียงผิดอาจเรียกเครื่องมือแชตได้ จึงควรทดสอบคำเรียกและไมค์ก่อน คำสั่งที่ระบบแชตเดิมต้องยืนยัน เช่นปิดโปรแกรม ยังคงต้องยืนยันตามเดิม

ตัวอย่าง: “ลุงเดฟ เปิด Notepad”, “ลุงเดฟ เปิดเพลงแจ๊ส”, “ลุงเดฟ เตือนฉันให้พักอีก 5 นาที”

## หยุดและยกเลิก

- **Ctrl+Alt+M**, ปุ่มแถบ **ปิดไมค์** หรือเมนู **ปิดไมโครโฟนทันที**: ปิด tracks ไมค์และยกเลิกการถอดเสียงที่ค้าง ผลที่กลับมาหลังยกเลิกจะไม่ถูกส่ง
- ปุ่ม ✕ ปิดเฉพาะหน้าตั้งค่า ถ้าไมค์ยังทำงานจะมีแถบปิดไมค์อยู่บนจอ
- Escape ในหน้าตั้งค่า ปิดไมค์และปิดหน้าต่าง
- เปลี่ยนตัวละคร ซ่อนตัวละคร ปิดแชต หรือออกจากโปรแกรม หยุดการฟัง
- ระบบ Uncle เดิมพักรับเสียงระหว่าง AI ตอบ/สร้างเสียง/เล่นเสียงเพื่อลดการฟังตัวเอง ใช้ปุ่มหยุดเสียงพูดหรือหยุดงานเมื่อต้องยกเลิก ส่วน ElevenLabs สนทนาและพูดแทรกได้ตาม [คู่มือ Voice Agent](VOICE_AGENT_TH.md)
- หยุดไมค์หลังส่งคำสั่งแล้ว ไม่ย้อนกลับการกระทำที่เริ่มไปแล้ว
- เปลี่ยนคีย์ลัดได้ใน ตั้งค่า › ระบบ › คีย์ลัด; หากลงทะเบียนไม่ได้ให้แก้คีย์ที่ชนหรือใช้ปุ่ม/เมนูแทน

## ข้อมูลเสียงและข้อจำกัด

- เสียงรอคำเรียกถอดในเครื่องเสมอ ไม่ใช้บริการออนไลน์ตรวจคำเรียก
- เมื่อตั้ง Gemini/OpenAI เสียงคำสั่งหลังปลุกและช่วงคุยต่อส่งไปบริการที่เลือก หากพูดคำเรียกพร้อมคำสั่ง ระบบตรวจ local ก่อน แล้วส่งคลิปเดิมถอดซ้ำผ่าน cloud หลังพบคำเรียก; ถ้าผลไม่ชัดจะขอให้พูดใหม่
- Local STT สร้างไฟล์ WAV/transcript ชั่วคราวในโฟลเดอร์ temp ของระบบ และลบทิ้งใน finally หลังสำเร็จ/ผิดพลาด/ยกเลิก หาก process/เครื่องล่ม ไฟล์ชั่วคราวอาจตกค้าง
- จำกัดประโยคประมาณ 24 วินาทีและ payload ไม่เกิน 30 วินาที ไม่บันทึกเสียงลงประวัติแชต แต่ข้อความที่ส่งเข้าแชตใช้ประวัติเดิม
- อัลกอริทึมตรวจเสียงพูดใช้ระดับเสียง จึงอาจรับเพลง/เสียงทีวี ควรใส่หูฟัง ปรับ threshold และใช้โหมดกดพูดในห้องเสียงดัง
- การตั้งคำเองเป็นการเทียบ transcript ไม่ใช่การแยกว่าใครเป็นผู้พูด ไม่ใช่ voice authentication
- Backend ใน source นี้ใช้ `gpt-4o-mini-transcribe` สำหรับ OpenAI และ `gemini-3.5-transcribe` สำหรับ Gemini ชื่อที่ระบุคือค่าของโค้ด ไม่ใช่การรับรองอายุบริการหรือสิทธิ์บัญชีปัจจุบัน

## การตรวจสำหรับนักพัฒนา

`npm test` ครอบคลุม settings, PCM/WAV, คำเรียก, consent, cancel/stale results และคำสั่งเสียง ใช้ `node scripts/smoke-listening.js` กับแอป `--dev` เมื่อต้องตรวจอุปกรณ์จริง ผล QA รุ่นก่อนอยู่ [archive](archive/QA_HISTORY_TH.md); automated fixtures ไม่แทน benchmark เสียงมนุษย์
